STOCK THEME MONITOR

テーマ監視のワークフロー

平日朝7:20にクラウド（GitHub Actions）で自動起動し、約6分で「新テーマの発見 → テーマごとの計測 → 判定 → レポートと通知」までを行います。

1. 全体の流れ

左が処理の順番、右の点線が過去の記録（比較の基準に使う）

2. 局面の判定順

上から順に調べ、最初に当てはまった局面になる（毎朝ゼロから判定）

3. 新テーマの扱い

自動で増やし、自動で減らす。残したいものだけ手動で常設にする

4. 操作とファイル

手動実行はGitHubのActions画面からも可能（morning › Run workflow）

やりたいこと方法
今すぐ朝の処理を実行gh workflow run morning
候補を常設テーマにする.venv/bin/python monitor.py --adopt 原発
追加テーマを外す.venv/bin/python monitor.py --drop 原発
固定テーマ・銘柄を編集themes.py
レポートを見るmamimusshu.github.io/theme-report
実行ログGitHub › stock-theme-monitor › Actions
候補の採用などを反映変更後に git pull → 編集 → git push（記録は毎朝クラウドがコミット）
